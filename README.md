# alicicek/homebrew-tap

Homebrew tap for [llmpilot](https://github.com/alicicek/llmpilot) — your Claude accounts, on autopilot (macOS).

```sh
brew install alicicek/tap/llmpilot        # the CLI + daemon
brew install --cask alicicek/tap/llmpilot # the menu bar app
```

Formulae and casks here are published automatically by the llmpilot release pipeline. Do not edit by hand.
